🎯 QR Code Generator untuk Testing Presensi

📋 Cara Penggunaan:

  1. Klik tombol "Generate QR Code" di bawah
  2. QR Code akan muncul (bisa berisi teks apa saja)
  3. Scan QR ini menggunakan aplikasi presensi
  4. Sistem akan catat kehadiran dengan timestamp WIB
  5. User yang sama hanya bisa scan 1x per hari

Catatan: QR Code ini hanya berisi teks "PRESENSI_2025" untuk trigger presensi. Sistem akan ambil data user dari login session.
